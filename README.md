# Личное приглашение для Кариши

Откройте index.html в браузере. Страница работает без сборки.

Сценарий: запечатанное письмо → три интерактивные подсказки → приглашение → ответ.
Место выбирает автор приглашения, Карише ничего заполнять не нужно.

В начале script.js укажите выбранное место в place, дату и время в when.
Пока указаны «Пока сюрприз. Я всё выбрал.» и «В четверг, в 13:00».

Кнопки ответа открывают меню «Поделиться», если оно доступно.
Иначе сообщение копируется или показывается для ручной отправки.
Автоматической отправки и сбора ответов нет.
